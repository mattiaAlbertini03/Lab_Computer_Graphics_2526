#ESERCIZIO 3

In questo programma viene caricato una sfera presa da un file .obj che viene 
generata all'interno di un cubo e inizia a rimbalzare al suo interno. 

Con il mouse è posibile interagire con l'ambiente. 
Si puo' interagire con l'ambiente anche tramite i bottoni. 

All'interno del file html vengono definiti il vertex shader e il frament shader.

Il codice javascript usa le librerie [m4](m4.js) e [webglUtils](webgl-utils.js).
